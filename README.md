# ห้องเรียนธรรมชาติของ ไบรอั่น

เว็บเรียนสำหรับเด็ก เรื่องแสงแดด น้ำ ดิน และอากาศ ตัวละครชื่อไบรอั่น

## รันโปรเจกต์

```bash
npm install
node scripts/restore-assets.mjs
npm run dev
```

เปิดเบราว์เซอร์ที่พอร์ตที่สคริปต์บอก

รูปภาพ เสียงพูด และฟอนต์อยู่ในโฟลเดอร์ `assets-b64/` แล้วสคริปต์จะแปลงกลับเป็นไฟล์จริงใน `public/`
